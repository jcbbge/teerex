## Actual source disposition

**No agent-core wrapper is deleted or overwritten by this patch.** That is deliberate: the requested deletion precondition is behavioral parity, and the remaining gates above are observable gaps, not paperwork. No legacy source is replaced by a thin shell script that silently preserves the same unsupported behavior. No personal shell/security configuration, executable symlink, hook installation, service or Rex restart is performed.

The paired migration should land with the integrator's accepted combined commands, not ahead of them:

1. Inventory and rewrite the actual launch/hook/palette/relay callers to the managed profile and typed store interfaces. Preserve explicit host/socket/registry paths and same-server reply limitations; migrate detached agents to visible surfaces.
2. On disposable authorized harnesses, prove initial protocol consumption, real ACK, later brief consumption, exact standing flags, idle/error callbacks and non-destructive custom-function handling. No paid model eval is implied or run by the synthetic fixture suite.
3. Decide and document the launch-wrapper guard/call-through and cross-host reply-address gaps. Until those are replaced, keep their current working source rather than claiming parity.
4. Only after those gates pass, delete the corresponding stopgap source in the **same paired source change**, including references/install instructions. Use actual agent-core source transfer/review and its own tests. Do not treat deleting a personal symlink, editing an installed file, or publishing a teerex-only alias as source migration.

The recommendation for alpha.5 is to ship the tested managed lifecycle as an explicitly bounded experimental path, with this migration gate still open, rather than delete working guards/alerts or claim the entire operating layer is migrated. Full arbitrary cross-host metadata routing and guaranteed alerts after loss of the visible supervisor need additional proven authority, not a guessed PID, a hidden watcher or a forged `dead` state.
