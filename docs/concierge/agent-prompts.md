# Bounded utility task prompts

Adapt the exact target and intended result before using a prompt. These briefs
cover teerex utilities; agent roles and launch instructions belong to rexconfig.

## Install or update

> Follow the rexconfig build and install procedure for the selected machines.
> Select an exact teerex build, verify complete managed release inventory and
> archive checksums, retain the prior release, and report per-host installed
> identity plus focused live checks. Do not restart Rex. Keep unknowns and failed
> checks visible. Use docs/concierge/setup.md for the current procedure links.

## Inspect a pane

> Read the authorized pane with teerex observe on the explicitly selected host.
> Report source identity, completeness and relevant evidence. Do not infer work
> completion from screen changes or idle state. Preserve private captures in the
> authorized work location and report their paths when needed.

## Use one utility

> Read the installed command help and its item README. Apply the requested
> utility operation to the exact authorized host and target. Check the exit and
> complete receipt, run the focused result check, and remove temporary surfaces
> created for the task. Report effects, proof and remaining unknowns.
