# teerex utility guides

teerex supplies Rex reads, waits, guarded sends, visible commands, surfaces, boards,
records, recovery and named-host utilities. Start with [the usage guide](../usage.md)
and the installed `teerex --help`.

- [Setup](setup.md): select and verify a build; inspect the installed interface.
- [Features](features.md): the current command families and their contracts.
- [Task prompts](agent-prompts.md): bounded installation, read and utility-use briefs.
- [Earlier releases](follow-ons.md): where historical release evidence lives.

Agent launches, scratchpads, hooks, messaging wrappers and the seat belong to
[rexconfig](https://github.com/jcbbge/rexconfig#agent-commands). teerex provides
the underlying Rex utilities; it does not control that lifecycle.
