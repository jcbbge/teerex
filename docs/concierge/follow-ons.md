# Historical follow-ons

Version-specific shipment evidence lives under [releases](../releases/). Those
pages preserve the command sets and test receipts of their frozen releases;
they do not describe the current executable or select a new installation.

For current behavior use [features](features.md), [usage](../usage.md), and the
installed command help. For installation use [setup](setup.md). Retired launch,
profile, channel and agent-control features are outside teerex’s current scope.
