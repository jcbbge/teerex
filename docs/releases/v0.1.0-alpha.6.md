# teerex v0.1.0-alpha.6

alpha.6 is the release of 13 November 2026's overnight run. In it, Josh's operating layer for Rex grew from a set of careful primitives into the full roadmap: everything since alpha.5, with 134 commits on main. Every change passed the four hosted CI lanes (Linux API13, Mac API10/12/13) on its exact head, and was installed and live-checked on hive and the M5 before this tag. [The README](../../README.md) gives the shape of the CLI; agents read [docs/agents.md](../agents.md).

## What's new

**Agents and messages**
- `send` guards a human's draft by default: it waits while they type, sends, then restores the draft exactly (#4).
- `agents launch` queues concurrent launches, and archives dead records itself (`agents prune`).
- Stop reports now arrive for Claude, Codex (`notify`) and pi (extension).
- `agents human`: Josh types `claude`, `codex` or `pi` and gets a tracked, visible agent with its standing flags (`agents shell`).
- `ask` types a decision card into the target pane. Prepared cards (`--deliver paste`) follow the attention policy.
- `clutch take|release`: a cooperative human hold on a pane. A server-enforced version needs Rex itself (upstream R1/R6).
- `mcp`: teerex as native MCP tools for Claude Code, Codex and pi.

**Panes and runs**
- `surfaces resolve` accepts labels and id suffixes (#2).
- `surfaces ensure` finds or creates a pane, either in one session or across the whole server (`--session any`).
- `surfaces session ensure` finds or creates a session (#23).
- `run-visible` gains:
  - jobs tracking and `--no-deadline`;
  - a launch-scoped channel with live `receipts.jsonl`;
  - `--detach`, with `run-visible receipt` to read the result;
  - environment hand-off that never leaves values on disk.
- `observe --tail` returns the newest output; `observe --state` reports whether an agent is idle, working, awaiting a choice or erroring.
- `--socket` now defaults from `REX_SERVER`.
- `watch` and `compare` accept `--view progress-v1`, which ignores spinners and timers.
- Legacy `run` and `offstage` now work on Linux.

**Fences, records, boards**
- `agents fence-probe` checks a sandbox before the harness starts. It judges protected paths by host identity, and keeps its evidence off the worker's output (`--evidence-fd`).
- `records` is the single private store for reasoning, evidence, park/resume/navigate (H01, U01/U02) and decisions with pins (H06).
- `replay record|play|live` records terminal sessions and replays them byte for byte (H03); [observation terms](../observation-terms.md) (H08).
- `boards fleet` is now keyboard-driven.
- `boards calls` shows a private log of every teerex call (#13); `boards friction` is opt-in (H02).
- The inbox rotates old records into an archive instead of refusing new ones (#15).

**Cartridges**
- `teerex cartridges` is now part of the core CLI.
- `cartridges doctor` and `cartridges repair` inspect and clean up the cartridge root; `jobs doctor` does the same for job registrations.
- `observe` is the first cartridge marked **ready** on both platforms. Independent R12 runs on hive and the M5 support it (`tools/acceptance/results/`).
- Linux catalogs now include `run` and `offstage`.

**Fixes:** #1, #6, #9, #12, #17, #18, #19, #20, #22, the Mac lock-create race, and a jobs reader that failed with WouldBlock.

## Install

```sh
tools/install/teerex-install upgrade --version v0.1.0-alpha.6 --prefix ~/.local/opt/teerex-managed
teerex cartridges install --all --catalog DIR --allow-experimental --apply   # DIR = the extracted cartridge archive
```

Earlier versions stay installed for `teerex-install rollback`.

## Limits that remain

- Rex has no input lease, so `clutch` and the draft guard are cooperative. The requests to Rex are written up as R1–R7.
- Mac binaries are ad-hoc signed only. Developer ID signing, notarization and signed catalogs (U08/Q09) need credentials Josh has not chosen.
- API11, other OS versions and Intel Macs are untested.
