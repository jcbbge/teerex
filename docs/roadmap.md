## Read the checkboxes as bounded contracts

- **Checked:** the specifically described capability is shipped, or a named design alternative has been resolved. This does not certify every platform, build, security property or larger historical group.
- **Unchecked / gap:** unfinished coverage, documentation or product-quality work. Its finish criteria say what evidence is still needed; an untested guarantee is not a demonstrated failure.
- **Unchecked / partial original:** the source proposal is not fully realized. Historical assistant suggestions are not automatically Joshua's commitments; no missing portion is silently approved by listing it.
- **Unchecked / host-blocked:** teerex cannot supply the stated Rex-wide guarantee through the tested contract. Client conventions are not a substitute.
- **Unchecked / future option:** recommended or retained for consideration, not selected implementation scope. Unsupported-by-design features do not become promises.

Agents and humans are both first-class users. Ranking favors trustworthy evidence, fewer unnecessary calls, bounded resources, straightforward human UX and independent cartridge lifecycle. It assumes these help repeated terminal work; actual productivity and interruption benefits have not been measured. There are no percentage-complete estimates or deadlines.

## Everything shipped, and what it enables

The following checklist describes the **released alpha.4** surface, including capabilities inherited from earlier alphas. Source links point to the owners; their increment-time validation paragraphs may describe older milestones. The tagged release guide and the support matrix below settle current release scope.

- [x] **S01 — `observe`: bounded, explicitly addressed terminal evidence.** Select an exact socket/session/block and obtain terminal screen-and-scrollback text, process/foreground cwd, reported directory, status reports, source identity and observation ID. Humans and agents can inspect one intended target without focus guesses or input. Capture is a bounded **prefix**, potentially omitting the latest prompt; five serial reads are non-atomic and freshness remains unknown. Mac/Linux, numeric API10–13. [Source, contract and tests](../items/observe/README.md); C01/C02/C04/C23.
- [x] **S02 — `compare`: offline evidence changes.** Compare two explicitly selected compatible observations, separating changed values, changed availability and unknown comparisons without repeating raw capture. This reduces rereading and prevents equal partial prefixes being called unchanged full screens. No activity, phase, success or permission inference. [Contract](../items/observe/README.md#what-c03-adds-and-teaches); C03.
- [x] **S03 — `watch`: bounded foreground change/status-evidence waits.** One persistent Rex/Lua collector compares samples with the original baseline until evidence changes, a selected root/named report differs and matches, deadline or cancellation. This removes repeated model wait/inspect turns and client launches without a daemon. A retained `done` report is not actual process exit; a quiet deadline is not completion. Mac/Linux, numeric API10–13. [Contract and public tests](../items/observe/README.md#what-c09s-bounded-observation-wait-adds-and-teaches); C08/C09.
- [x] **S04 — `run`: local argv execution and collection.** Execute literal argv/cwd on the Rex **CLI host**, retain bounded stdout/stderr bytes, and return real exit/signal/timeout evidence with invocation-owned process-group cleanup. This avoids simulated typing and repeated output polling for noninteractive work. Split Unicode/binary output is preserved; cancellation retains collected output. Runtime Mac/API10–13, not execution inside a selected terminal or on a remote server, not a hidden-agent launcher or sandbox. [Source and public tests](../items/run/README.md); C06/C08–C11.
- [x] **S05 — `offstage`: invocation-owned off-layout command PTY.** Create and verify one command block outside the layout, capture bounded evidence, then close/verify absence within the controller's scoped lifecycle. Useful for explicit short command experiments without cluttering the workspace. Runtime Mac/API13 only. No durable supervision, agent hiding, SIGKILL recovery, descendant-proof cleanup or isolation. [Source and tests](../items/offstage/README.md); C12 and part of C13.
- [x] **S06 — `spawn`: visible worker creation.** Create a new window-attached terminal using explicit argv/cwd, agent-core metadata and report-to IDs, then verify exact returned placement/identity. Gives agents and humans a visible, addressable worker rather than a headless exception. Mac/Linux, numeric API10–13. Creation is not readiness; lost ACK can conceal creation and is not automatically retried. [Source and tests](../items/spawn/README.md); later mandatory scope.
- [x] **S07 — `send`: explicit whole-message transport.** Read one selected message file, target full IDs, send paste then Enter and return their separate acknowledgements. Enables deliberate agent messages with fewer low-level calls. Mac/Linux, numeric API10–13. Not atomic delivery, prompt safety, exclusive input, proof of consumption, or safe automatic retry after lost ACK. [Source and tests](../items/send/README.md); later mandatory scope, not C05.
- [x] **S08 — `doctor`: selected compatibility/drift diagnosis.** Inspect independent CLI/server identities, five consumed method shapes and four Lua function shapes, optionally against an explicit saved baseline. Helps distinguish advertised support and drift from guesses before using observe/watch/run. Runtime Mac/API10–13 only; it does not execute sample jobs, certify terminal behavior, assess permissions or cover every shipped command. [Source and tests](../items/doctor/README.md); C25/C27 subset.
- [x] **S09 — `maneuver-check`: manual saved-evidence recognition.** Check one strict manual definition or a bounded library of 1–16 definitions/0–64 declared relations against explicit saved API13 observations. Unique/mismatch/unknown/ambiguous results and SHA256 file receipts let agents reuse recognizable saved starts without first-match guessing. Optional `--before` checks declared endpoint evidence, not an executed transition or chronology. Offline Mac/Linux; no learning, input execution, fresh-state guard or enforced stop. [Source, library and tests](../items/maneuvers/README.md); follow-on and C18 subset.
